# Lepton AI (lepton-ai)

Lepton AI was acquired by NVIDIA in 2025 and the platform is now branded **NVIDIA DGX Cloud Lepton**. It is a fully managed AI platform that connects developers to global GPU compute across a federated network of cloud providers, with managed endpoints, dev sessions, distributed training, and batch processing.
